# ✈️ Air Traffic India Analysis Dashboard

An interactive Power BI dashboard that analyzes India's air traffic data to uncover passenger and freight movement trends. The dashboard provides dynamic visualizations and actionable insights, helping users explore transportation patterns through an intuitive and interactive interface.

---

# 📖 Short Description

The **Air Traffic India Analysis Dashboard** is a Power BI project developed to transform raw air traffic data into meaningful business insights. It enables users to analyze passenger and freight movement across different months, quarters, and flight types using interactive charts, KPI cards, and filters.

This dashboard demonstrates how data visualization can simplify complex datasets and support data-driven decision-making.

---

# 🛠 Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Dashboard development and visualization
- 📂 **Power Query** – Data cleaning and transformation
- 🧠 **DAX (Data Analysis Expressions)** – Calculated measures and KPIs
- 📑 **Microsoft Excel** – Source dataset
- 📈 **Data Modeling** – Table relationships and filtering
- 📁 **File Formats** – `.pbix`, `.xlsx`, `.png`

---

# 📂 Data Source

**Source:** Microsoft Excel Dataset

The dataset contains air traffic information including:

- Passenger From India
- Passenger To India
- Freight From India
- Freight To India
- Year
- Quarter
- Month
- Flight Type (Domestic / Foreign)

---

# 🌟 Features & Highlights

## 📌 Business Problem

Air traffic data contains thousands of records, making it difficult to identify passenger movement, freight trends, and seasonal patterns using spreadsheets alone.

Organizations require an interactive dashboard to monitor transportation performance and make informed business decisions.

---

## 🎯 Goal of the Dashboard

The primary objective of this dashboard is to:

- Analyze passenger traffic trends.
- Monitor freight movement.
- Compare inbound and outbound passenger traffic.
- Identify monthly and quarterly performance.
- Enable interactive data exploration through filters.
- Support data-driven decision-making.

---

## 📊 Walkthrough of Key Visuals

### 📌 KPI Cards

The dashboard displays important business metrics including:

- Total Passenger From India
- Total Passenger To India

These KPIs provide an instant overview of overall passenger traffic.

---

### 📈 Passenger Trend Analysis

A line chart visualizes monthly passenger movement, making it easy to identify seasonal travel trends and fluctuations throughout the year.

---

### 📊 Quarterly Performance

A bar chart compares passenger traffic across all four quarters, helping users evaluate quarterly performance.

---

### 📦 Freight Analysis

The dashboard includes freight movement visualizations to analyze cargo transportation patterns and monthly freight distribution.

---

### 🌍 Geographic Map

An interactive world map provides a geographical overview of airline operations and traffic distribution.

---

### 🎛 Interactive Filters

Users can filter the dashboard by:

- Year
- Month
- Flight Type

This enables customized analysis based on user requirements.

---

### 📋 Detailed Data Table

A tabular view displays detailed passenger and freight information for deeper analysis.
